How Claude built this

Claude, an AI model made by Anthropic, wrote the code for this page, checked it, and published it. The author directed every step through five prompts in one conversation on November 27, 2026. This page lists the tools, the checks, and those prompts.

Tools

The author already had accounts with Claude Code, GitHub, and Vercel and had used all three before this project.

Claude CodeAnthropic's coding agent, run in the Claude desktop app. It wrote the HTML, CSS, and JavaScript, ran the checks below, and handled publishing.
GitHubStores the code in a private repository with a history of every change.
VercelHosts the public site. It is linked to the GitHub repository, so each update pushed to GitHub goes live in about a minute.
D3 and no-ai-slopD3 is a free JavaScript library that draws the map. No-ai-slop is a free set of writing rules from Peter Yang that Claude followed for every sentence on the site.

The data is the research behind an earlier version of this map, the DDF Funders Network. That research found 13 programs where the Doris Duke Foundation pooled money with other funders. This version keeps the same data and changes only how it is shown.

How accuracy was checked

  • Claude copied the data out of the original page's code with a script instead of retyping it, so no names or numbers were rewritten by hand. The script counted 13 programs, 81 funders including DDF, and 24 endowment figures, which match the original.
  • Every program keeps the source link from the original research. Two programs have no amount on record, and one has no source link. The site says so on their cards instead of filling in a guess.
  • Totals and comparisons on the page are calculated by the code from that data. Claude spot-checked them by hand: the two Environment programs add up to $105M ($102.5M plus $2.5M), and Ford's $15.8B endowment is about 7 times DDF's $2.19B.
  • Each amount carries a short note on what it counts, such as "5-year pledge" or "first round only," taken from the original research. Comparing a pledge to a single round of grants would be misleading without it.
  • Claude caught one of its own errors along the way. In chat it first said 56 funders had no endowment figure, and the page's own count showed 57. The page uses 57.

How usability was checked

  • Claude opened the site in a browser built into the Claude app and looked at screenshots after each change, at desktop width and at phone width (375 pixels), in both light and dark mode.
  • It tested every way into the details: clicking programs, funders, and DDF on the map; the area buttons; the program list; the "try one of these" buttons; the search box, including a name that does not exist; the Escape key; and clicking empty space to reset.
  • It confirmed that hovering a bar in a chart lights up the matching dots on the map, and that moving the mouse away puts the map back.
  • The screenshots turned up problems that Claude then fixed: the map sat too small in its box, funder names overlapped program names, one label ran off the edge, and the $500M label spilled outside its chart.
  • The author reviewed the result and spotted a gap Claude had missed. The original map showed connections when you hovered over a dot, and the first version of this one did not. That became the fourth prompt.
  • After each publish, Claude loaded the live Vercel site to confirm every file came through and the page had no errors.

The prompts

These are the prompts in order. Click "Claude's reply" to see a summary of what came back.

Prompt 1

Give a first attempt at recreating this in an intuitive way that is interactive for users with limited prior knowledge.

"This" is the original DDF Funders Network map.

Claude's reply

Claude rebuilt the map around one question: who funds programs with the Doris Duke Foundation? DDF sits in the center, the 13 programs circle it, and each funder sits beside the programs it backs. Funders in two or more programs are gold and labeled.

Clicking anything fades the rest of the map and opens a card with the amount, what the amount means, the full funder list, and the source. A "Start here" card offers three things to try. The year slider, zoom buttons, and dragging from the original were left out to keep the page simple.

Prompt 2

Keep it private

Answering Claude's question about whether the GitHub repository should be public or private.

Claude's reply

The repository stays private. The live site on Vercel is still public, so anyone with the link can view it.

Prompt 3

What are some other helpful components that could be in this, to make it more informational for users?

Claude's reply

Claude suggested nine additions, split by whether the data already existed:

  • With existing data: (1) a timeline of when each program started, (2) a chart comparing program amounts, (3) a chart comparing funder sizes, (4) shareable links, and (5) a sources list with a data download.
  • Needing new research: (6) a one-sentence description of each program, (7) a tag for pooled funds versus looser collaborations, (8) a note on what is missing from the research, and (9) a short "what is a pooled fund?" explainer.
Prompt 4

Let's do 1, 2, 3. It's also missing the hovering feature on the original one.

Claude's reply

Claude added the three charts under the map. The timeline shows that one program began in 2008 and the other 12 started between 2019 and 2026. The amount chart cuts Humanity AI's $500M bar short so the smaller programs stay readable. The funder chart marks DDF's size with a dashed line on every bar.

For hovering, Claude matched the original. Hovering a dot fades everything it is not connected to and shows a pop-up with its details. Hovering a bar, a list entry, or a name on a card previews it on the map the same way.
